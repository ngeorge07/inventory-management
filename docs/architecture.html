Request & Data Flow

1
User sets filters Time period, warehouse, category, and order status are held in the shared useFilters composable and drive every view.
2
View calls the API client Components import api from api.js, which builds URLSearchParams and drops any filter equal to 'all'.
3
HTTP request to FastAPI Axios issues a GET to http://localhost:8001/api/… with query params; CORS permits the cross-port call from :3000.
4
Backend filters in memory The endpoint runs apply_filters() (warehouse / category / status) and filter_by_month() (month or Qx-2025) over the loaded lists.
5
Pydantic validates & serializes Results are validated against response_model types (InventoryItem, Order, …) and returned as JSON.
6
Vue renders reactively Raw data lands in refs; derived values (totals, charts, status badges) come from computed properties that re-render the template.
